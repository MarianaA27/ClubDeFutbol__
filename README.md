# PaladinesFC — Re-arquitectura

Re-arquitectura del sistema de escritorio PaladinesFC (Python, CustomTkinter, SQL Server) para la gestión de un club de fútbol formativo.

Trabajo final de Arquitectura de Sistemas, Universidad Católica Luis Amigó.

**Equipo:** Giany Andrés Salazar Bustamante · Mariana Aguilar Alcaraz · Carlos Daniel Palacios Murillo · Juan Camilo Moreno Pérez
